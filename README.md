# 🎮 GameZone Retro

Uma página simples em HTML para representar uma loja de jogos clássicos.

## 📋 Sobre o projeto

O projeto apresenta a loja **GameZone Retro**, com informações sobre consoles, preços de jogos e links para navegação.

## 🕹️ Conteúdo

- 🎮 Título da loja
- 📝 Texto com **negrito** e *itálico*
- 🔗 Link interno para a tabela de preços
- 🌐 Link externo para o Instagram
- 🖼️ Imagem relacionada a jogos retro
- 📋 Lista de consoles
- 💰 Tabela com jogos, consoles e preços
- ©️ Rodapé com o nome da loja

## 💻 Tecnologias utilizadas

- HTML5
- Tags básicas de HTML
- Nenhum CSS ou JavaScript
